💻 تعلم لغة C++

لغة C++ تعتبر من أقوى لغات البرمجة في العالم، وتستخدم في تطوير الألعاب، أنظمة التشغيل، الذكاء الاصطناعي، والبرامج السريعة.


📚 ما هي المكتبات؟

المكتبات في C++ هي ملفات جاهزة تحتوي على أوامر ووظائف تساعد المبرمج.


مثلاً مكتبة: 

#include <iostream>

هذه المكتبة مسؤولة عن الإدخال والإخراج، أي الطباعة على الشاشة واستقبال البيانات.


📖 شرح أول كود

#include <iostream>

using namespace std;

int main(){

cout << "Hello World";

return 0;

}

🔹 include تستدعي المكتبة

🔹 main هي بداية البرنامج

🔹 cout تستخدم للطباعة

🔹 return 0 تعني انتهاء البرنامج
